# Sample AI Agent

This project demonstrates the fundamentals of building an AI Agent using Python and the OpenAI API.

It explores how AI agents interact with users, use tools, execute functions, and perform tasks using Large Language Models (LLMs).

### Technologies
- Python
- OpenAI API
- LLMs
- Function Calling
- Tool Calling

### Purpose
A beginner-friendly project to understand AI Agent development and practical applications of LLMs.
